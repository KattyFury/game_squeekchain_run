Data & game rules

Live mode maps hardware-measured API speed to a bounded game speed; it is not a 1:1 simulation of the physical wheel. Live pauses when the hamster rests or data is unavailable. Practice uses its own speed and is labeled LOCAL. Space is the only game control.

Scores and obstacles are calculated locally. The work counter seeds the initial live obstacle layout only. There are no SQK rewards, transactions, server leaderboards, or historical replays. This prototype has not been built through the IMD swarm.
