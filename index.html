Source, rules & verification

Recorded hardware challenges use an immutable snapshot of eligible hardware passages from the Squeekchain API. Everyone receives the same source window, seed, obstacles and speed timeline. This is recorded device evidence, not live activity, independently verified signatures, SqueekCore-certified work or onchain scores.

Each passage interval maps to 1.1 / interval seconds radians per second, clamped to 0.55–1.4 and smoothed at 120 Hz. Gaps above 3 seconds, ineligible segments and continuity breaks split the source. Challenges last 30–60 seconds. This mapping is a game rule, not a physical wheel simulation.

Live mode requires fresh, accepted hardware measurements. It freezes on idle, errors, stale data or an epoch change. Practice is local and uses its own best. The server recomputes shared scores from Space input ticks using the same rules. Replay checking limits score tampering; it does not prevent bots or prove who played. Names are unauthenticated aliases.

No wallets, payments, SQK prizes or IMD submission are included. The project has not yet been built through the IMD swarm.
